# Composer note types

Every `*.json` file in this folder is loaded by the Level Composer app (it ships inside the app build) and by
the Unity importer (Tools > Rythm RPG > Level Composer > Import Combat Level). Each file adds new note gimmicks
or overrides built-in ones by id. The `examples/` subfolder is not loaded; `examples/bomb.json` shows every field.
Full documentation: `Assets/LevelComposer/README.md`.
